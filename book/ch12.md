## The outside judge

The Lean Kernel Arena (arena.lean-lang.org) holds a suite of exports —
proofs a checker must accept, forgeries and resource bombs it must
refuse — and a leaderboard of checkers that is nobody's homework. The
local snapshot of its suite is the 199-file set this book has been
citing since chapter 8; the hosted suite adds the big real-library
corpora and totals 234. As of this book's measurement date the top
score on the board is 208 of 234, held by several checkers including
the official kernel itself. Nobody holds 234.

This project's standing, measured and recorded: 199 of 199 on the local
suite — 127 of 127 accepted, 72 of 72 refused. The four hardest of
those files (a reduction-depth tower, a deep application spine, a cache
punisher, and the magma memory monster of chapter 10) each also defeat
between four and nine checkers on the public board. The submission
interface is a pull request pointing at a public git revision; the
checker's side of the contract is its exit codes, and the exercise
below runs that contract end to end on an accept and a refusal.

## What a scoreboard cannot say

The arena checks verdicts, not understanding — a checker can hold 199
and still harbor a check nobody has aimed at yet (chapter 11's absent
check, forever). And it cannot grade this book's actual deliverable:
whether a reader can now meet an unseen rule and say what breaks
without it. That evidence has its own fixed bar — the posttest written
before chapter one — and collecting it from real readers is an open
row in the notebook, not a box this page may tick.

What the scoreboard does say, it says about no one's intentions. The
underscore of chapter 9, the dead lift cache of chapter 10, the
String.ofList correction of chapter 8 — every one was surfaced by an
oracle that did not care what the author believed. That is the claim of
chapter 1 closing its own loop: a checker cannot be argued with, and so
the only way to trust one is to hand it to judges who will not argue
either. Build the thing, keep the notebook, point it at a real library,
and let somebody else keep the score.

## Try it

```ts
// Chapter 12 — The arena.
// The contract an outside judge holds a checker to: exit codes.
// 0 accept, 1 reject, 2 decline, anything else is a checker bug.

import { ExportParser } from "../../src/export/parser.ts";
import { Checker, tryStep, type CheckFailure } from "../../src/checker.ts";

function check(lines: string[]): { failures: CheckFailure[] } {
  const parser = new ExportParser();
  const checker = new Checker();
  const failures: CheckFailure[] = [];
  for (const line of lines) {
    const step = tryStep(() => {
      const d = parser.processLine(line);
      if (d !== null) checker.addDecl(d);
    });
    if (!step.ok) failures.push(step.error);
  }
  return { failures };
}

// The arena convention, as implemented at this checker's boundary:
function exitCode(failures: CheckFailure[]): number {
  if (failures.length === 0) return 0; // accept
  return failures.every((f) => f.kind === "refusal") ? 1 : 3; // reject | bug
}

const meta =
  '{"meta":{"exporter":{"name":"lean4export","version":"3.1.0"},' +
  '"format":{"version":"3.1.0"},"lean":{"githash":"5045d005","version":"4.34.1"}}}';

// A file the checker must accept: one honest axiom.
const good = [
  meta,
  '{"in":1,"str":{"pre":0,"str":"T"}}',
  '{"il":1,"succ":0}',
  '{"ie":0,"sort":1}',
  '{"axiom":{"name":1,"levelParams":[],"type":0,"isUnsafe":false}}',
];

// A file the checker must refuse: a theorem claiming to prove Type.
const bad = [
  meta,
  '{"in":1,"str":{"pre":0,"str":"oops"}}',
  '{"il":1,"succ":0}',
  '{"ie":0,"sort":1}',
  '{"thm":{"name":1,"levelParams":[],"type":0,"value":0,"all":[1]}}',
];

const g = check(good);
const b = check(bad);
console.log(`good file: exit ${exitCode(g.failures)}`);
const first = b.failures[0];
const code = first !== undefined && first.kind === "refusal" ? first.code : "?";
console.log(`bad file : exit ${exitCode(b.failures)} [${code}]`);

// The distinction the exit codes encode is the one chapter 10 paid for:
// a refusal (1) and a crash (3) must never be confused, in either
// direction. A checker that crashes on a forgery has not refused it.

// To break it: return 1 from exitCode unconditionally. Every bad test
// still "passes" — and so does every good test the checker actually
// failed on. An oracle can only see what the contract lets it see; the
// contract is therefore part of the kernel's trusted surface.
```

Expected output:

```text
good file: exit 0
bad file : exit 1 [typeMismatch]
```
