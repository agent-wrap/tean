## What the user gets back

Accepting a data type is only half the transaction. The kernel answers
with a new constant, the **recursor**, which is both the induction
principle and the only way to compute with the data.

You have written its runtime half many times. **The recursor is `reduce`
for the declared type** — the fold you would write by hand, with an
initial value per base case and a combining step per recursive case.
What makes it more than a fold is its *type*, and the type has three
kinds of pieces:

```text
  Nat.rec :  (C : Nat -> Sort u)                  <- the MOTIVE
          -> C zero                               <- a MINOR PREMISE
          -> ((a0 : Nat) -> C a0 -> C (succ a0))  <- a MINOR PREMISE
          ->                '--' the induction hypothesis
             (t : Nat)                            <- the MAJOR PREMISE
          -> C t
```

- the **motive** `C` — what is being proved or built, as a family over
  the type (and over its indices, which is why chapter 6 kept parameters
  and indices apart);
- one **minor premise** per constructor — show `C` holds for that
  constructor, given it holds for every recursive argument (those extra
  arguments are the *induction hypotheses*);
- the **major premise** — the actual value being destructed.

Read `C` as a constant family and the whole thing is `reduce` with its
accumulator type written down. Read `C` as a predicate and the same
line is proof by induction. One constant, both jobs, because in this
system they are the same job.

## Derived, not trusted

The crucial word is *derived* [R: WF-REC-DERIVE](RULES.md#wf-rec-derive). The recursor's type and
its computation rules are a pure function of the declaration. A checker
that instead reads them from its input has handed the attacker the
induction principle: one forged rule, and False has a proof. This book's
checker derives its own recursor, compares the input's version against
it, and refuses on any mismatch — then re-checks its *own* derivation for
type preservation, because a derivation bug is a soundness bug too.

The exercise derives the type above from nothing but a list of
constructors, and the "to break it" at the end deletes one line of the
derivation to show what the omission costs.

## Iota

The computation rule, **iota**, is the pattern-match you already know:
a recursor applied to a constructor selects that constructor's minor
premise and recurses [R: RED-IOTA](RULES.md#red-iota). `double 2` in the exercise runs three
iota steps and stops. Combined with chapter 4's machinery, iota is also a
*definitional equality*: `double 2 == 4` holds by computation alone, and
the judge of chapter 5 can see it without help.

Projections, from chapter 7, are iota for structures with the motive
left out: there is only one constructor to select, so no case split is
needed and no minor premise has to be supplied. That is why a structure
gets its own reduction rule rather than going through its recursor.

Two refinements of iota remain — one for a narrow class of propositions,
one for a primitive family that is not an inductive type at all. They
are chapter 9.

## Try it

```ts
// Chapter 8 — Recursion from data.
// Derive a recursor's type from a declaration, then run iota by hand.

// A constructor, reduced to what the derivation needs: its name and its
// argument kinds ("self" is a recursive argument, a name is anything else).
interface Ctor {
  name: string;
  args: string[];
}

// Derive the recursor's type, exactly as the kernel does: one motive C,
// one minor premise per constructor, then the major premise.
function deriveRecType(typeName: string, ctors: Ctor[]): string {
  const minors = ctors.map((c) => {
    const binders: string[] = [];
    const ihs: string[] = [];
    const names: string[] = [];
    c.args.forEach((a, i) => {
      const v = `a${i}`;
      names.push(v);
      binders.push(`(${v} : ${a === "self" ? typeName : a})`);
      if (a === "self") ihs.push(`C ${v}`); // induction hypothesis
    });
    const applied = names.length === 0 ? c.name : `(${c.name} ${names.join(" ")})`;
    const parts = [...binders, ...ihs, `C ${applied}`];
    // A minor premise with its own binders is one argument: parenthesize.
    return parts.length === 1 ? parts.join("") : `(${parts.join(" -> ")})`;
  });
  return [`(C : ${typeName} -> Sort u)`, ...minors, `(t : ${typeName})`, `C t`].join(" -> ");
}

console.log(`Nat.rec  : ${deriveRecType("Nat", [
  { name: "zero", args: [] },
  { name: "succ", args: ["self"] },
])}`);
console.log(`Bool.rec : ${deriveRecType("Bool", [
  { name: "true", args: [] },
  { name: "false", args: [] },
])}`);

// Now iota, the computation rule, on real data. The recursor applied to
// a constructor picks that constructor's minor premise — nothing more.
// Read natRec below as `reduce` for this data type: `onZero` is the
// initial value, `onSucc` is the combining step, `major` is the thing
// being folded. The kernel writes one of these for every type you
// declare — and its TYPE is the induction principle.
type Nat = { kind: "zero" } | { kind: "succ"; pred: Nat };
const zero: Nat = { kind: "zero" };
const succ = (pred: Nat): Nat => ({ kind: "succ", pred });

function natRec<T>(onZero: T, onSucc: (n: Nat, ih: T) => T, major: Nat, log: string[]): T {
  switch (major.kind) {
    case "zero":
      log.push("iota: zero");
      return onZero;
    case "succ":
      log.push("iota: succ");
      return onSucc(major.pred, natRec(onZero, onSucc, major.pred, log));
  }
}

function show(n: Nat): string {
  return n.kind === "zero" ? "zero" : `(succ ${show(n.pred)})`;
}

// double, defined by recursion ON THE DATA: no loop, no mutation.
const double = (n: Nat, log: string[]): Nat =>
  natRec<Nat>(zero, (_pred, ih) => succ(succ(ih)), n, log);

const log: string[] = [];
console.log(`double 2 = ${show(double(succ(succ(zero)), log))}`);
console.log(`steps    = ${log.join(", ")}`);

// To break it: in deriveRecType, drop the `C ${v}` induction hypothesis
// line and look at Nat.rec again. The succ case loses its `C a0`
// argument — the recursor can still case-split, but it can no longer
// recurse, and everything from addition upward stops being definable.
// The type of the recursor IS the induction principle, derived, not
// trusted: chapter 13 shows what one forged line in it buys an attacker.

export {}; // keeps this file a self-contained module
```

Expected output:

```text
Nat.rec  : (C : Nat -> Sort u) -> C zero -> ((a0 : Nat) -> C a0 -> C (succ a0)) -> (t : Nat) -> C t
Bool.rec : (C : Bool -> Sort u) -> C true -> C false -> (t : Bool) -> C t
double 2 = (succ (succ (succ (succ zero))))
steps    = iota: succ, iota: succ, iota: zero
```
