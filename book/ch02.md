## Why names fail

Write the identity function twice: `fun x => x` and `fun y => y`. They are
the same function, and a checker must treat them as the same term. With
named variables, every equality test, every substitution, and every cache
key has to reason "up to renaming" — the lambda-calculus word is
*alpha-equivalence* — and each of those places is a chance to get capture
wrong (capture: a moved variable ending up pointing at the wrong binder).

The standard fix is due to de Bruijn (1972): delete the names. A **bound
variable** is a number, written `#0`, `#1`, `#2`, that counts how many
binders sit between the variable and the binder it belongs to:

```text
       fun  =>  fun  =>  (  #1    #0  )
        |        |          |      |
        |        |          |      '-- 0 binders crossed on the way out,
        |        |          |          so: the nearest `fun`
        |        '----------+--------- 1 binder crossed,
        '-------------------'          so: the outer `fun`
```

`#0` is always the nearest enclosing binder. The identity function is
`fun => #0` — there is exactly one way to write it, so structural
equality is plain tree equality and alpha-equivalence costs nothing.

Two moves and one derived quantity do all the work in this chapter.

## Lift

An index is only meaningful relative to its depth. Move a term under a
binder and every index that points *outside* the term must grow by one, or
it will be captured by the binder it just crossed:

```text
   before            f #0            #0 points one level out of this term
   under a new  ->   fun => f #1     lifted: #1 points at the SAME place
   binder                            (the new `fun` did not capture it)
```

The operation `lift(e, start, amount)` raises every index that is `start`
or larger, and `start` itself increases each time the walk enters a
binder. Indices below `start` point at binders inside `e` and must not
move.

## Instantiate

To apply `fun => body` to an argument `a`, replace `#0` in `body` by `a`.
Three cases, by comparison with the current depth `d`:

1. `#d` is the variable being replaced: the result is `a`, lifted by `d`,
   because `a` just moved under `d` binders.
2. An index above `d` pointed past the eliminated binder: it drops by one.
3. An index below `d` belongs to a binder inside the body: unchanged.

The reverse operation, *abstract*, turns a chosen **free variable** back
into `#0` and wraps a binder around the result. Free variables are the
third piece: when a checker needs to look *under* a binder (to check a
function body, say) it replaces `#0` with a fresh free variable — a name
that cannot clash because it is a serial number — does its work in that
open form, and abstracts afterward. A free variable's type is recorded in
a side table, and looking it up is the entire typing rule for variables
[R: T-VAR](RULES.md#t-var). Abstract-then-instantiate returning the original term is the
round-trip invariant that the property tests of this book's checker hammer
on generated terms. The exercise below implements lift and instantiate
only; free variables arrive with the real checker, from chapter 5 on.

In formal notation, instantiation is written $e[a/x]$ — "*e* with *a* for
*x*" — and the lift bookkeeping is exactly what makes that innocent
bracket well-defined. When a paper says "substitution is
capture-avoiding", this chapter is the footnote it is avoiding writing.

## The derived quantity

Every node can cache one small number: the smallest `n` such that all its
*loose* indices — indices that point past the node's own binders — are
below `n`. Call it the loose-bound-variable range. A node whose range is
zero is closed: lift and instantiate can return it unchanged without
looking inside. On real input this one field turns substitution from "walk
everything" into "walk the spine that actually mentions the variable".
Chapter 12 puts a number on it.

## Try it

```ts
// Chapter 2 — Variables without names.
// Binding is arithmetic: an index counts binders outward.

type Expr =
  | { kind: "bvar"; idx: number } // bound variable: #0 is the nearest binder
  | { kind: "const"; name: string }
  | { kind: "app"; fn: Expr; arg: Expr }
  | { kind: "lam"; type: Expr; body: Expr }; // the binder has no name

const bvar = (idx: number): Expr => ({ kind: "bvar", idx });
const app = (fn: Expr, arg: Expr): Expr => ({ kind: "app", fn, arg });
const lam = (type: Expr, body: Expr): Expr => ({ kind: "lam", type, body });
const cnst = (name: string): Expr => ({ kind: "const", name });

// Raise every loose index >= start by `amount`. A substituted term that
// crosses a binder must not capture that binder's variable.
function lift(e: Expr, start: number, amount: number): Expr {
  switch (e.kind) {
    case "bvar":
      return e.idx >= start ? bvar(e.idx + amount) : e;
    case "const":
      return e;
    case "app":
      return app(lift(e.fn, start, amount), lift(e.arg, start, amount));
    case "lam":
      // Inside the binder, indices shift by one: start moves with us.
      return lam(lift(e.type, start, amount), lift(e.body, start + 1, amount));
  }
}

// Replace #0 by `a` (and renumber what pointed past it).
function instantiate(e: Expr, a: Expr, depth = 0): Expr {
  switch (e.kind) {
    case "bvar":
      if (e.idx === depth) return lift(a, 0, depth);
      return e.idx > depth ? bvar(e.idx - 1) : e;
    case "const":
      return e;
    case "app":
      return app(instantiate(e.fn, a, depth), instantiate(e.arg, a, depth));
    case "lam":
      return lam(instantiate(e.type, a, depth), instantiate(e.body, a, depth + 1));
  }
}

function show(e: Expr): string {
  switch (e.kind) {
    case "bvar":
      return `#${e.idx}`;
    case "const":
      return e.name;
    case "app":
      return `(${show(e.fn)} ${show(e.arg)})`;
    case "lam":
      return `(fun : ${show(e.type)} => ${show(e.body)})`;
  }
}

const T = cnst("T");
// fun x => fun y => x y   is   fun => fun => #1 #0
const inner = lam(T, app(bvar(1), bvar(0)));
const twoBinders = lam(T, inner);
console.log(show(twoBinders));

// Open the outer binder with the constant c: `inner` is its body, and the
// #1 inside it — one binder out — becomes c.
console.log(show(instantiate(inner, cnst("c"))));

// The capture case lift exists for: substitute (fun => #0 #1) for #0
// UNDER a binder. The inner #1 must still point outside after the move.
// The target #0 sits under that binder, so it appears as #1 there.
const needsLift = lam(T, app(bvar(0), bvar(1)));
console.log(show(instantiate(inner, needsLift)));

// To break it: delete the call to lift inside instantiate and rerun.
// The last line changes: the moved #1 now points at the wrong binder.
// That silent wrong answer, not a crash, is why capture is feared.

export {}; // keeps this file a self-contained module
```

Expected output:

```text
(fun : T => (fun : T => (#1 #0)))
(fun : T => (c #0))
(fun : T => ((fun : T => (#0 #2)) #0))
```
