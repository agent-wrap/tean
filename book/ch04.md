> **Claim.** Deciding whether two types are equal requires an interpreter,
> and that interpreter is substitution run at the head.
>
> **You are here.** Terms, indices, universes (chapters 1–3). **Next:**
> Chapter 5 — The judge.

## Why a checker computes

Here is the surprise this chapter exists for. A checker never evaluates a
program for its answer — and yet it ships an interpreter, because the
typing rules keep asking "are these two types equal?", and types contain
programs. A term of type `Vector T (2 + 3)` must be usable where a
`Vector T 5` is expected. Equality of types is therefore *equality up to
computation*, and the checker must be able to run `2 + 3`.

The formal relation is written $e \rightsquigarrow e'$ ("*e* reduces to
*e'*"), and the base rule is **beta** [R: RED-BETA]:

$$(\mathrm{fun}\ x:A \Rightarrow e)\ a \rightsquigarrow e[a/x]$$

Apply a function: substitute the argument into the body. Chapter 2 built
the bracket; this chapter just pulls its trigger. Two more rules unfold
things that are definitionally transparent:

- **zeta** unfolds a `let`: a let-bound name is not an abstraction barrier,
  just shared text, and the checker may always inline it
  [R: RED-ZETA] [R: T-LET];
- **delta** unfolds a constant that has a definition: replace the name by
  its value, with the universe levels of the use site substituted in
  [R: RED-DELTA] [R: T-CONST].

## Weak head normal form

The interpreter must be lazy, and lazily lazy. The workhorse is **weak
head normal form** — *whnf* from here on: reduce at the head of the term,
repeatedly, until the head is a binder, a sort, or a stuck application —
and then stop. Never reduce under a binder, never reduce an argument until
something demands it.

The reason is economy of refusal. When the checker compares two types, the
common case is that their heads already agree or already disagree; fully
evaluating the arguments is work nobody asked for. On a real library the
difference is not stylistic — reduction depths reach five digits, and the
measured costs fill chapter 10.

Two implementation facts matter enough to state now, each one a rule with
a measurement behind it:

1. **Discharge the whole spine at once.** `f a b c` with `f` a triple
   lambda becomes one substitution of three arguments, not three
   substitutions. One argument at a time re-walks the body quadratically.
2. **Delta is directed by height.** Every definition records how tall its
   unfolding stack is; when comparing two constants, unfold the taller
   one first, and try a cheap argument-by-argument match before unfolding
   both. Chapter 5 uses this inside the equality judge.

## Where whnf stops

The exercise prints three one-line traces. Watch the second one: a redex
*inside* a lambda body survives whnf untouched, and that restraint is the
entire point of the "weak" in the name. Full normalization is whnf applied
everywhere, and the checker almost never needs it.

## Try it

```ts
// Chapter 4 — Computation is substitution.
// whnf: reduce the head until it stops, and not one node more.

type Expr =
  | { kind: "bvar"; idx: number }
  | { kind: "const"; name: string }
  | { kind: "app"; fn: Expr; arg: Expr }
  | { kind: "lam"; type: Expr; body: Expr };

const bvar = (idx: number): Expr => ({ kind: "bvar", idx });
const app = (fn: Expr, arg: Expr): Expr => ({ kind: "app", fn, arg });
const lam = (type: Expr, body: Expr): Expr => ({ kind: "lam", type, body });
const cnst = (name: string): Expr => ({ kind: "const", name });

function lift(e: Expr, start: number, amount: number): Expr {
  switch (e.kind) {
    case "bvar":
      return e.idx >= start ? bvar(e.idx + amount) : e;
    case "const":
      return e;
    case "app":
      return app(lift(e.fn, start, amount), lift(e.arg, start, amount));
    case "lam":
      return lam(lift(e.type, start, amount), lift(e.body, start + 1, amount));
  }
}

function instantiate(e: Expr, a: Expr, depth = 0): Expr {
  switch (e.kind) {
    case "bvar":
      if (e.idx === depth) return lift(a, 0, depth);
      return e.idx > depth ? bvar(e.idx - 1) : e;
    case "const":
      return e;
    case "app":
      return app(instantiate(e.fn, a, depth), instantiate(e.arg, a, depth));
    case "lam":
      return lam(instantiate(e.type, a, depth), instantiate(e.body, a, depth + 1));
  }
}

// Definitions the head may unfold (delta).
const env = new Map<string, Expr>();

// Weak head normal form, with a step log.
function whnf(e: Expr, log: string[]): Expr {
  if (e.kind === "app" && e.fn.kind === "lam") {
    log.push("beta");
    return whnf(instantiate(e.fn.body, e.arg), log);
  }
  if (e.kind === "app" && e.fn.kind === "app") {
    const fn = whnf(e.fn, log);
    return fn === e.fn ? e : whnf(app(fn, e.arg), log);
  }
  const head = e.kind === "app" ? e.fn : e;
  if (head.kind === "const" && env.has(head.name)) {
    log.push(`delta: ${head.name}`);
    const v = env.get(head.name);
    if (v !== undefined) return whnf(e.kind === "app" ? app(v, e.arg) : v, log);
  }
  return e; // a lam, a bare const, or a stuck application: weak head stops.
}

function show(e: Expr): string {
  switch (e.kind) {
    case "bvar":
      return `#${e.idx}`;
    case "const":
      return e.name;
    case "app":
      return `(${show(e.fn)} ${show(e.arg)})`;
    case "lam":
      return `(fun => ${show(e.body)})`;
  }
}

function run(label: string, e: Expr): void {
  const log: string[] = [];
  const r = whnf(e, log);
  console.log(`${label}  ~>  ${show(r)}   [${log.join(", ")}]`);
}

const T = cnst("T");
// two = fun f => fun x => f (f x)
const two = lam(T, lam(T, app(bvar(1), app(bvar(1), bvar(0)))));
env.set("two", two);

run("two g", app(cnst("two"), cnst("g")));
// The body of a lambda is NOT reduced: weak head normal form stops at
// the first binder. The redex (two g) inside survives untouched.
run("fun => (two g)", lam(T, app(cnst("two"), cnst("g"))));
// Head redexes chain: ((fun => #0) two) g needs beta, delta, beta.
run("((fun => #0) two) g", app(app(lam(T, bvar(0)), cnst("two")), cnst("g")));

// To break it: make whnf reduce inside lam bodies too (full
// normalization). Every answer stays "the same" up to computation — and
// chapter 10 measures the price: real proofs reach reduction depths in
// the tens of thousands, and eager reduction does all of that work even
// when the first head symbol already decides the comparison.

export {}; // keeps this file a self-contained module
```

Expected output:

```text
two g  ~>  (fun => (g (g #0)))   [delta: two, beta]
fun => (two g)  ~>  (fun => (two g))   []
((fun => #0) two) g  ~>  (fun => (g (g #0)))   [beta, delta: two, beta]
```
